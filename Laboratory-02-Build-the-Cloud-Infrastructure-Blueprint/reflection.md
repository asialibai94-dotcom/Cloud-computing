# Mission 2 – Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, the compute resource is the most important cloud infrastructure component because it provides the processing power needed to run applications and services. Without compute resources, the other components would not be able to perform useful tasks. However, I also learned that compute works together with storage, networking, and the operating system.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable and flexible operating system for servers. During this laboratory, I used Linux commands in the KillerCoda environment to check the operating system, CPU, RAM, disk, hostname, and IP address. This helped me understand how cloud servers can be managed through a terminal.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it helps engineers understand the resources, configuration, and design of a system before deployment. It also makes it easier to troubleshoot problems and allows other team members to understand the decisions made during the planning process.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using different terminal commands and identify compute, storage, networking, and operating system resources. I also learned how to compare AWS, Microsoft Azure, and Google Cloud services, create a simple cloud infrastructure diagram, and organize technical documentation using Markdown and GitHub.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I added a complete laboratory project with organized documentation, infrastructure findings, cloud provider comparisons, and an architecture diagram. I also practiced making meaningful commits and organizing files into folders. This makes my portfolio more structured and shows the skills I learned from the laboratory.
