
# Mission Reflection

This laboratory activity helped me understand how cloud storage works and why different storage types are used for different purposes. I learned the difference between block storage, file storage, and object storage. Block storage is useful for systems that need fast and direct access to data, while file storage organizes data into files and folders. Object storage is useful for storing large amounts of unstructured data such as images, videos, and documents.

One of the most important things I learned was how Docker can be used to deploy a cloud storage service. Instead of installing everything manually, Docker allows applications and their dependencies to run inside containers. This made the deployment process easier to understand and showed me how containers can be useful in cloud computing.

I also learned how MinIO can provide an object storage environment similar to cloud storage services. Creating a bucket and uploading a test file helped me understand how data can be organized and stored using object storage. I also learned that ports are important because they allow us to access services running inside a container through a web browser.

During the activity, I encountered some problems while deploying MinIO and accessing its web console. These challenges helped me practice troubleshooting Docker commands, container status, and port access. I learned that checking error messages and verifying whether a container is running are important steps when troubleshooting.

Overall, this laboratory activity improved my understanding of cloud storage, Docker, and object storage. It also helped me become more comfortable with using command-line tools and troubleshooting technical problems. The activity showed me how cloud data engineers manage and organize data storage services in a practical environment.
