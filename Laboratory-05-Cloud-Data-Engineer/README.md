# Laboratory 05 - Cloud Data Engineer

## Mission Overview

In this laboratory activity, I learned about cloud storage and the different ways data can be stored in the cloud. I deployed MinIO using Docker to create an S3-compatible object storage server. I also created a bucket and uploaded a test file through the MinIO web console.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access a cloud service through a web interface using port forwarding.
- Create a storage bucket and upload objects.
- Document cloud storage operations using Markdown.
- Add the laboratory activity to my GitHub Cloud Computing Portfolio.

- Understanding different types of cloud storage
- Using Docker to deploy a cloud service
