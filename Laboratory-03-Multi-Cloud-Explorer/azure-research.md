# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides services for computing, storage, networking, databases, artificial intelligence, security, and application development.

## Global Infrastructure

Azure provides a global infrastructure consisting of regions and datacenters located across different geographic areas. Azure geographies contain one or more regions and are designed to support requirements such as data residency, compliance, availability, and low latency.

## Cloud Management Console

The Azure portal is a web-based management interface used to create, configure, monitor, and manage Azure resources and services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual machines for running applications and workloads.

### 2. Azure Blob Storage

Azure Blob Storage provides cloud object storage for large amounts of unstructured data.

### 3. Azure Virtual Network

Azure Virtual Network provides private networking for Azure resources and allows organizations to control network communication.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users, applications, and resources.

## Three Advantages

1. Strong integration with Microsoft technologies
2. Global cloud infrastructure
3. Supports hybrid and enterprise environments

## Typical Enterprise Use Cases

Azure can be used for:

- Enterprise application hosting
- Windows Server workloads
- Microsoft 365 and identity integration
- Hybrid cloud environments
- Database and analytics solutions
