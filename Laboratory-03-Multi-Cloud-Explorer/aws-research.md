# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of infrastructure, storage, database, networking, security, and application services. AWS allows organizations to build, deploy, and scale applications using cloud resources.

## Global Infrastructure

AWS uses a global infrastructure made up of geographic Regions and Availability Zones. Each Region is a separate geographic area, while Availability Zones are isolated locations within a Region. AWS states that its infrastructure currently spans 39 geographic Regions and 124 Availability Zones.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services and resources. Users can manage services such as computing, storage, networking, databases, and security through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides object storage for storing and retrieving data.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create isolated virtual networks for AWS resources.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources through users, roles, and permissions.

## Three Advantages

1. Wide range of cloud services
2. Global infrastructure and scalability
3. Flexible resources for different workloads

## Typical Enterprise Use Cases

AWS can be used for:

- Web and mobile application hosting
- Data storage and backup
- Enterprise application deployment
- Database and analytics workloads
- Scalable online services
