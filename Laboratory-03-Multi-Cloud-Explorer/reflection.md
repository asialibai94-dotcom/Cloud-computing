# Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most was Google Cloud Platform (GCP). I liked how it provides different services for computing, storage, databases, analytics, containers, and application development. I also found its services useful for modern applications, especially data analytics and cloud-based applications.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP are similar because they all provide cloud computing services such as computing, storage, networking, databases, security, and identity management. They also have regions and zones that help improve availability and performance. All three platforms allow users to access resources through cloud-based tools and services without maintaining physical servers.

## 3. How do business requirements influence cloud platform selection?

Business requirements are important when choosing a cloud platform because every organization has different needs. Factors such as budget, security, performance, location, existing technologies, scalability, and required services should be considered. For example, a company that already uses many Microsoft products may benefit from Azure, while a company focused on data analytics may prefer GCP.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

Acting as a Cloud Solutions Consultant taught me that choosing a cloud platform is not only about selecting the most popular provider. I learned that I need to understand the client's requirements first and then compare the available services, advantages, limitations, cost, security, and performance before making a recommendation.
