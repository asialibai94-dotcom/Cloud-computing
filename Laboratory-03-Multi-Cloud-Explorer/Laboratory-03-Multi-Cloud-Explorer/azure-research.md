# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides services for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development.

## Global Infrastructure

Azure provides cloud infrastructure through regions and availability zones. Availability Zones are physically separate locations within an Azure region and are designed to help protect applications from local infrastructure failures.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources and services.

## Four Core Services

1. Azure Virtual Machines – Provides virtual machines for computing workloads.
2. Azure Blob Storage – Provides object storage for unstructured data.
3. Azure Virtual Network – Provides networking capabilities for Azure resources.
4. Microsoft Entra ID – Provides identity and access management.

## Three Advantages

1. Strong integration with Microsoft technologies.
2. Wide range of enterprise cloud services.
3. Support for hybrid and enterprise environments.

## Typical Enterprise Use Cases

Azure can be used for enterprise applications, Windows Server workloads, Microsoft 365-related environments, databases, application development, virtual machines, data analytics, and hybrid cloud solutions.
